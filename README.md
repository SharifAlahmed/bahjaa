# منصة بهجة

منصة عربية تحوّل الكتب إلى فهم كامل وخطوة تطبيقية — للقادة ورواد الأعمال العرب.

## التشغيل محلياً

```bash
npm install
cp .env.example .env.local   # عدّل NEXT_PUBLIC_SITE_URL إلى http://localhost:3000
npm run dev
```

## الصفحات

| المسار | الوصف |
|---|---|
| `/` | الرئيسية — أحدث الملخصات والأقسام |
| `/categories` | كل الأقسام |
| `/c/[slug]` | قسم واحد وملخصاته |
| `/s/[slug]` | الملخص — الأقسام 1-4 مجانية، 5-10 بعد الدخول |
| `/login` | دخول بالإيميل (Magic Link) |
| `/admin` | لوحة الأدمن — مراجعة ونشر وإخفاء وحذف |
| `/admin/preview/[slug]` | معاينة مسودة قبل النشر |

## المعمار

- **Next.js 15 (App Router)** + **Tailwind v4** + **Supabase**
- كل ملخص مخزّن كـ **JSON مهيكل** لا HTML — التصميم يعيش في `components/summary-*.tsx`.
  تغيير شكل كل الملخصات = تعديل ملف واحد.
- نظام التصميم كله في `app/globals.css` داخل كتلة `@theme`.

## الجدار المجاني — طبقتان

1. **في قاعدة البيانات:** دور `anon` ممنوع من قراءة عمود `content_full`
   (صلاحية على مستوى العمود). لا يمكن تجاوزه من المتصفح مهما فعل الزائر.
2. **في التطبيق:** `app/s/[slug]/page.tsx` لا يطلب العمود أصلاً بلا جلسة.

## الأدمن

صلاحية الأدمن = وجود الإيميل في جدول `bh_admins`، وتُفحص داخل Postgres
عبر الدالة `bh_is_admin()`. لا مفتاح خدمة سرّي في التطبيق.

لإضافة أدمن:
```sql
insert into public.bh_admins (email) values ('someone@example.com');
```

## إضافة ملخص

لا تحرّر في المتصفح. أرسل لكلود: «لخّص وانشر كتاب [الاسم]».
يصل كمسودة إلى `/admin` → راجع → اضغط نشر.

## جداول قاعدة البيانات

`bh_categories` · `bh_summaries` · `bh_admins`
(تعيش في مشروع Supabase نفسه مع أكاديمية الممكن، منفصلة تماماً بسابقة `bh_`)
